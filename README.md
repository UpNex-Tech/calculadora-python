🧮 Calculadora em Python

📌 Sobre o projeto
Este é meu primeiro projeto desenvolvido em Python, criado durante o primeiro semestre de Ciência da Computação.

O objetivo é praticar lógica de programação e compreender os fundamentos da linguagem Python.

🚀 Funcionalidades
- Adição
- Subtração
- Multiplicação
- Divisão
- Validação de entradas numéricas
- Tratamento de divisão por zero
- Menu interativo

🛠️ Tecnologias utilizadas
- Python 3
- Visual Studio Code
- Git e GitHub

▶️ Como executar
1. Instale o Python 3.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

`python calculadora.py`

📚 Conhecimentos praticados
- Variáveis e tipos de dados
- Operadores aritméticos
- Estruturas condicionais (`if`, `elif`, `else`)
- Laços de repetição (`while`)
- Funções
- Tratamento de exceções (`try` e `except`)
